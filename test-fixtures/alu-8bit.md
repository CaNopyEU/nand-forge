# 8-bit ALU v2

Bit-sliced ALU built entirely from NAND gates. Supports 8 operations selected by a 3-bit opcode, with Carry, Zero, and Negative flags.

## Modules

| Name | ID | Inputs | Outputs | Sub-modules | Description |
|------|----|--------|---------|-------------|-------------|
| NOT | mod-not | A | Out | 1x NAND | Inverter |
| AND | mod-and | A, B | Out | 2x NAND | Logical AND |
| OR | mod-or | A, B | Out | 3x NAND | Logical OR |
| XOR | mod-xor | A, B | Out | 4x NAND | Exclusive OR |
| MUX 2:1 | mod-mux2 | A, B, S | Y | NOT + 2x AND + OR | 2-input multiplexer |
| MUX 4:1 | mod-mux4 | D0–D3, S0, S1 | Y | 3x MUX 2:1 | 4-input multiplexer |
| Half Adder | mod-half-adder | A, B | S, C | XOR + AND | Sum and carry |
| Full Adder | mod-full-adder | A, B, Cin | S, Cout | 2x HA + OR | Ripple-friendly adder |
| NOR8 | mod-nor8 | D0–D7 | Out | 7x OR + NOT | 8-input NOR (for Zero flag) |
| ALU Slice | mod-alu-slice | A, B, Cin, Op0, Op1, Op2, ShiftIn | R, Cout | AND + OR + XOR + NOT + XOR(B_eff) + FA + 2x MUX4 | 1-bit ALU (8 ops) |
| 8-bit ALU | mod-alu8 | A[8], B[8], Op0, Op1, Op2 | R[8], Carry, Zero, Neg | 8x MUX2 + 8x ALU Slice + NOR8 + Splitter + Merger | Full 8-bit ALU with flags |

## Architecture

### ALU Slice v2 (1-bit, 3-path design)

```
Path 1 — Logic:
  AND(A,B), OR(A,B), XOR(A,B), NOT(A) → MUX4(Op0,Op1) → logic_result

Path 2 — Arithmetic:
  B_eff = XOR(B, Op0)                  (invert B for SUB)
  FA(A, B_eff, Cin) → Sum, Cout

Path 3 — Shift (from ALU8 level):
  ShiftIn = MUX2(A[i-1], A[i+1], Op0)  (left or right neighbor)

Final MUX4 (S0=Op1, S1=Op2):
  D0 = logic_result   (Op2=0, Op1=0)
  D1 = logic_result   (Op2=0, Op1=1)
  D2 = arith_sum      (Op2=1, Op1=0)
  D3 = shift_bit      (Op2=1, Op1=1)
```

### 8-bit ALU v2

```
A[8] → Splitter → a0..a7
B[8] → Splitter → b0..b7

8× MUX2(A[i-1], A[i+1], Op0) → shiftIn[i]   (0 for edges)

Op0 → ALU_Slice0(a0,b0,shiftIn0) → r0, c0
        ALU_Slice1(a1,b1,c0,shiftIn1) → r1, c1
        ...
        ALU_Slice7(a7,b7,c6,shiftIn7) → r7, c7

r0..r7 → Merger → R[8]
Carry = c7
Zero  = NOR8(r0..r7)
Neg   = r7
```

## Operation Table

| Op2 | Op1 | Op0 | Operation | Formula |
|-----|-----|-----|-----------|---------|
| 0 | 0 | 0 | AND | R = A & B |
| 0 | 0 | 1 | OR | R = A \| B |
| 0 | 1 | 0 | XOR | R = A ^ B |
| 0 | 1 | 1 | NOT | R = ~A |
| 1 | 0 | 0 | ADD | R = A + B |
| 1 | 0 | 1 | SUB | R = A - B (2's complement) |
| 1 | 1 | 0 | SHL | R = A << 1 |
| 1 | 1 | 1 | SHR | R = A >> 1 (logical) |

## Flags

| Flag | Source | Valid for |
|------|--------|-----------|
| Carry | Cout of bit 7 | ADD, SUB (Carry=1 = no borrow for SUB) |
| Zero | NOR8(r0..r7) = 1 when R=0 | All operations |
| Neg | Bit 7 of result | All operations |

## Test Scenarios

### ALU Slice
- A=1, B=1, Op=000 (AND) → R=1
- A=1, B=0, Op=001 (OR) → R=1
- A=1, B=1, Op=010 (XOR) → R=0
- A=1, Op=011 (NOT) → R=0
- A=1, B=1, Cin=0, Op=100 (ADD) → R=0, Cout=1
- A=1, B=0, Cin=1, Op=101 (SUB) → R=0, Cout=1

### 8-bit ALU — AND (Op=000)
- 0xFF AND 0x0F = 0x0F
- 0xA5 AND 0x5A = 0x00

### 8-bit ALU — OR (Op=001)
- 0xA0 OR 0x05 = 0xA5
- 0x00 OR 0x00 = 0x00

### 8-bit ALU — XOR (Op=010)
- 0xFF XOR 0xFF = 0x00
- 0xAA XOR 0x55 = 0xFF

### 8-bit ALU — NOT (Op=011)
- NOT 0xA5 = 0x5A
- NOT 0x00 = 0xFF
- NOT 0xFF = 0x00

### 8-bit ALU — ADD (Op=100)
- 5 + 3 = 8
- 0xFF + 0x01 = 0x00, Carry=1 (overflow)
- 0x00 + 0x00 = 0x00, Carry=0

### 8-bit ALU — SUB (Op=101)
- 5 - 3 = 2, Carry=1
- 0 - 1 = 0xFF, Carry=0
- 0 - 0 = 0, Carry=1

### 8-bit ALU — SHL (Op=110)
- 0x01 << 1 = 0x02
- 0x80 << 1 = 0x00 (Zero=1)
- 0xFF << 1 = 0xFE

### 8-bit ALU — SHR (Op=111)
- 0x80 >> 1 = 0x40
- 0x01 >> 1 = 0x00 (Zero=1)
- 0xFF >> 1 = 0x7F
